3,000枚の画像の説明を、腰を据えて書く人はいません。

どのストアでも、毎四半期、あらゆるToDoリストから消されていく作業です。そして誰も数えていないから、どれほどひどい状態なのかさえ言えません。このガイドは、その後半を解決します。読み終えるころには、alt text（代替テキスト）が何のためにあるのか、良いalt textとはどういうものか、Shopifyのどこにそれがあるのか、そしてアプリを一切インストールせずに約10分で、カタログのうち実際に説明されているのがどれだけかを確かめる方法がわかります。

## 誰があなたのalt textを読むのか

読み手は三者。同じ一文に、それぞれ別のものを求めています。

**Google。** 画像検索は、読める画像しか表示しません。説明のない画像は、順位が低いのではなく、土俵にすら上がっていません。また、ページの大半が写真である場合——商品ページはたいていそうです——Googleがそのページの内容を理解する手がかりもalt textです。

**AIショッピングエージェント。** これは新しい読み手で、最も急速に存在感を増しています。お客様に代わってカタログを閲覧するエージェントは、それをテキストとして読みます。沈黙した画像はエージェントにとって存在しません。そして、その画像が購入の決め手を担っていたなら、商品も存在しないのと同じです。

**スクリーンリーダーの利用者。** 写真を見ることができない人は、あなたのalt textを聞くか、「画像」とだけ聞くか、ファイル名を聞くことになります。法律が気にかけているのはこの読み手であり、良い説明とはどう聞こえるものかを教えてくれるのもこの読み手です。読み上げて役に立たないなら、それは役に立たない説明です。

三者が求めるものは、見た目ほど違いません。画像を見られない人の役に立つ一文を書けば、ほかの二者が求める一文も書けたことになります。

## Shopify自身が言っていること

いくつかの議論に決着がつくので、まず押さえておく価値があります。

- **512文字**が、商品のalt text欄の上限です。
- **125文字以内**が、Shopifyの推奨する長さです。
- **「〜の画像」は省く。** スクリーンリーダーはすでに画像であることを読み上げるので、その言葉は二重の無駄です。
- **キーワードは、説明になる場合だけ。** キーワードは「商品タイプ、色、素材、モデル名、用途など、画像を説明する場合にのみ」盛り込みます。詰め込みはスパムのシグナルとして扱われます。
- **装飾画像には空のalt属性を** ——属性がないのではなく`alt=""`です。こうすれば、スクリーンリーダーは背景の渦巻き模様を読み上げずに読み飛ばします。

出典：[How To Write Image Alt Text for SEO](https://www.shopify.com/blog/image-alt-text)および[Shopifyヘルプセンター](https://help.shopify.com/en/manual/products/product-media/add-alt-text)。

法律の背後にある基準としては、alt textは[WCAG 達成基準 1.1.1 非テキストコンテンツ](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content)にあたり、レベルAです。最も低い適合レベル、つまり満たせていないことが最も言い訳できないレベルです。

## 良いalt textとは

同じ商品に、三つの説明。

```
alt="IMG_2041-final-v3.jpg"
```

実質的に、欠落です。これは、欄に紛れ込んだファイル名です。

```
alt="メンズ オーガニック Tシャツ 最安値 送料無料"
```

ジャンク。何も説明しておらず、Googleにはスパムとして読まれ、読み上げれば意味不明です。この二つはどちらも、入力済みの欄を数えるだけのツールでは**カバー済み**として数えられる点に注意してください。カバー率のパーセンテージだけでは、ほとんど何もわからないのはそのためです。

```
alt="モスグリーン オーガニックコットンTシャツ - S - Tシャツ"
```

弱い。そして、これがいちばん興味深い例です。テンプレートが生成するのはこれで、一見問題なさそうに見えるからです。これは商品名です。ページを読んでいる買い物客は見出しですでにそれを知っていますし、スクリーンリーダーの利用者は写真ごとにそれを聞かされます。しかも商品の6枚の画像すべてで同じなので、6枚のうち5枚はまったく情報を持っていません。

```
alt="平らにたたんだモスグリーンのオーガニックコットンTシャツ。リブ編みの襟と、裾に刺繍された葉のモチーフが見える"
```

良い。*この写真*を説明しています。商品名だけでは足りないからこそ、マーチャントが撮ることを選んだ一枚を。

## 五つのルール

1. **フレームの中にあるものを説明する。** 商品の呼び名ではなく。
2. **1枚の画像に、1つの文。** 同じ商品の2枚の画像が同じalt textを共有しているなら、少なくともどちらか1枚は説明されていません。
3. **およそ125文字。** 具体的になるには十分な長さで、聞き取れるくらい短く。
4. **「〜の画像」「〜の写真」「〜のフォト」で始めない。**
5. **装飾には空の`alt=""`を。** 区切り線、渦巻き模様、スペーサー画像。語るべきことのないものにとって、沈黙こそが正しい説明です。

補足として6つ目：同じ写真でも、置かれる場所によって必要なalt textは変わります。商品ページでは衣服そのものですが、染色についてのブログ記事なら、色がテーマになるかもしれません。

## Shopifyのどこにalt textがあるのか

多くのマーチャントが思っているより多くの場所にあります。そして見落とされがちな場所ほど、大きな画像を抱えています。

- **商品メディア。** 管理画面 → 商品管理 → 対象の商品 → メディアをクリック → alt textの欄 → 保存。誰もが知っている場所です。
- **バリエーション画像。** メディアに紐づいているので商品のメディアから引き継がれますが、バリエーション固有の写真はそれ自体が別の画像であり、それ自体の一文に値します。
- **コレクション画像。** コレクション側で設定するもので、存在自体を忘れがちです。
- **ブログ記事の画像**（アイキャッチ画像を含む）。
- **テーマ画像。** バナー、スライダー、セクション画像、キャンペーン用のビジュアル。管理画面 → オンラインストア → テーマ → カスタマイズ → セクションをクリック → 画像の下の「編集」。ストアでいちばん大きく目立つ画像であり、同時にまったく説明されていない可能性がいちばん高い画像でもあります。みんなが探しに行く商品管理画面にはないからです。
- **テーマ設定内の画像。** テーマによっては、画像をセクションではなく設定に保持しています。これらにはShopify APIからまったくアクセスできません。「すべて」をカバーすると謳うツールを評価する前に、知っておく価値があります。

## 10分でできるセルフ監査

アプリは不要です。私たちのものも含め、どのツールを評価するよりも前にやってください。ここで出てくる数字こそ、どのベンダーの売り文句も上回らなければならない数字だからです。

1. ストアを開き、任意の商品画像を右クリックして**検証**（Inspect）を選びます。
2. `<img>`タグを見つけ、その`alt`属性を読みます。
3. これを**20枚の画像**で行います。売れ筋商品のメイン写真を5枚、ディテールや着用写真を5枚、テーマやバナーの画像を5枚、ブログの画像を5枚。
4. それぞれを4つのバケツに分類します。
   - **欠落** — 装飾ではない画像で、空、または属性がない
   - **ジャンク** — ファイル名、またはキーワードの羅列
   - **弱い** — 商品名、テンプレート、または6枚の画像すべてに同時に当てはまる文
   - **良い** — その特定の写真を説明している
5. 最後のバケツの数を数えます。

多くのストアが、予想していなかったことに気づきます。カバー率は高いのに、説明できている割合は低い。欄は埋まっている。でも、そこに入っている言葉は商品名なのです。

**そのギャップこそが、このガイドの要点のすべてです。** カバー率とは、空でない欄の数です。何かが説明されているかどうかの尺度ではありません。カバー率のパーセンテージを報告するツールはどれも——採点を始めるまでは私たちのものも含めて——誰にも読めないカタログで100%になりうる数字を報告しているのです。

## これで本当に法令に準拠できるのか？

それを約束できるツールはありません。約束するツールがあれば、そこからは離れるべきです。

事実として言えるのは、**欧州アクセシビリティ法（EAA）** が2025年6月からEコマースを対象にしていること、米国では**ADA**に基づくウェブアクセシビリティ訴訟が毎年数千件にのぼること、そして読み取れない画像は、一般的なストアフロントにおいて最も目につき、最も自動化で解消しやすい穴だということです。監査記録を残しながらそれをふさぐことは、何もしないより実質的に良い立場です。ただし、それは証明書ではありませんし、このガイドは法的助言でもありません。

## 自動化すべきとき、すべきでないとき

**手作業でやるべきなのは**、画像が数百枚未満の場合、あるいはカタログがあまり変わらない場合です。20枚ならひと午後。200枚なら何日分もの午後ですが、あなたはどのツールよりも良いalt textを書けるはずです。なぜその写真を撮ったのかを知っているのは、あなただからです。

**自動化すべきなのは**、枚数が数千枚に達している場合、毎週新商品が追加される場合、あるいはすでに二度挑戦して、ToDoの行が次の四半期に移っただけの場合です。3,000枚になると、失敗の原因は努力不足ではありません。すでにあるジャンクを採点するものも、書き込みを一つずつ検証するものも、来週火曜にアップロードする商品を拾うものもなく、いつの間にか止まっても誰も見ていない。それが原因です。

どちらを選ぶにしても、いま手作業で使ったのと同じ4つのバケツで判断してください。どのベンダーにも、こう聞いてみてください。_すでにあるものを採点するのか、それとも数えるだけなのか？_ たいていは、数えるだけです。
